`code` — может исследовать проект, изменять файлы, запускать команды и проверять результат.
`ask` — может анализировать проект и отвечать на вопросы, не внося изменений.
`debug` — может искать причины ошибок, исправлять код и проверять исправления.
`plan` — может изучать проект и составлять план изменений без редактирования файлов.
